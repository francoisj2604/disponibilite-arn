# Disponibilité ARN

Interface web pour l’affichage iPad au local W et le pilotage depuis l’iPhone.

GitHub Pages sert le dossier `docs` de la branche `main`. Le site fonctionne en démonstration tant que `docs/config.js` ne contient pas l’URL du service de synchronisation. Les trois Memoji sont attendus dans `docs/images` sous les noms `disponible.jpeg`, `occupe.png` et `absent.png`.
